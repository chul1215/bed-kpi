## 🔴 중대 문제 발견: DRG 매칭 실패

### 문제 개요
심평원(HIRA) 데이터와 병원(SMC) 데이터 간 매칭이 거의 실패하여 시스템 핵심 기능 작동 불가

### 통계
- **진단명 매칭률**: 2.1% (14개 / 663개)
- **환자 데이터 커버율**: 2.8% (963명 / 33,853명)
- **매칭 실패**: 32,890명 (97.2%)

### 근본 원인
**HIRA vs SMC 데이터 구조 차이**

| 구분 | HIRA (심평원) | SMC (병원) |
|------|---------------|------------|
| 분류 체계 | DRG 기반 | ICD-10 기반 |
| 중심 | 수술/시술 행위 | 질환/진단명 |
| 예시 | "간 이식술", "대동맥판막 수술" | "담석증", "무릎관절증" |
| 목적 | 포괄수가제 환자 분류 | 질병 분류 |

### 구체적 사례

**매칭 성공 (14개)**:
- 협심증 (357명) → HIRA에 "협심증" 항목 존재
- 두통 (271명) → HIRA에 "두통" 항목 존재
- 급성 신부전 (85명) → HIRA에 "급성 신부전" 항목 존재

**특징**: 수술 없는 단순 내과적 질환만 매칭 성공

**매칭 실패 (상위 10개, 14,902명)**:
1. 기타 의학적 관리... (3,190명) - HIRA에 해당 항목 없음
2. 담석증 (1,166명) - HIRA에는 "담낭 수술" 등으로 분류
3. 무릎관절증 (1,157명) - HIRA에는 "슬관절 치환술" 등으로 분류
4. 양성 신생물 (1,038명) - HIRA에는 부위별 수술로 분류
5. 뇌경색증 (801명) - HIRA에는 "뇌혈관 수술" 등으로 분류
6. 급성 충수염 (790명) - HIRA에는 "충수절제술"로 분류
7. 위장염 (693명) - 매칭 불가
8. 대퇴골 골절 (516명) - HIRA에는 "대퇴골 골절 수술"로 분류
9. 전정기능 장애 (477명) - 매칭 불가
10. 어지럼증 (425명) - 매칭 불가

### 영향 분석

#### 1. 시스템 기능 장애
```
KPI 지표          현재 상태
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
평균 LOS 갭      NaN (계산 불가)
추가 병상일수    0일 (계산 불가)
현재 가동률      109.97% (정상)
목표 가동률      109.97% (변화 없음)
```

#### 2. 대시보드 표시 문제
- 의료진별 KPI: target_los, los_gap, additional_bed_days 모두 NaN

#### 3. 비즈니스 영향
- ❌ 심평원 기준 대비 개선 목표 설정 불가
- ❌ 의사 결정 근거 부재
- ❌ 정량적 목표 수립 불가
- ❌ 병상 가동 최적화 계획 수립 불가

```bash
python3 generate_static_dashboard.py
```

```python
# 기존 (절대 기준)
los_gap = hira_target_los - current_los

# 변경 (상대 기준)
los_gap = current_los - hospital_avg_los  # 병원 평균 대비
# 또는
los_gap = current_los - dept_avg_los      # 진료과 평균 대비
```

**장점**:
- ✅ 즉시 구현 가능 (1-2일)

**템플릿 수정**:
```jinja2
<!-- 기존 -->
{% if doctor.los_gap >= 0 %}

<!-- 수정 -->
{% if doctor.los_gap is not none %}
    {% if doctor.los_gap >= 0 %}
        <span class="positive">+{{ "%.1f"|format(doctor.los_gap) }}일</span>
    {% else %}
        <span class="negative">{{ "%.1f"|format(doctor.los_gap) }}일</span>
    {% endif %}
{% else %}
    <span style="color: #95a5a6;">-</span>
{% endif %}
```

**적용 파일**:
- `doctor.html`
- `disease.html`
- `department.html`
- `index.html`

**결과**:
- ✅ NaN 값이 있어도 페이지 정상 표시
- ✅ "-" 기호로 매칭 실패 표시
- ✅ TypeError 발생 방지

### 3. 정적 HTML 경로 수정 (완료 ✅)

**문제**: 절대 경로(`/upload`, `/department`) 사용으로 file:// 프로토콜에서 작동 불가

**해결**:
```python
# 같은 디렉토리 레벨
html = html.replace('href="/upload"', f'href="index_{period}.html"')
html = html.replace('href="/"', f'href="index_{period}.html"')
html = html.replace('href="/department"', f'href="department_{period}.html"')

# 서브디렉토리 (doctors_*, diseases_*)
html = html.replace('href="/"', f'href="../index_{period}.html"')
html = html.replace('href="/department"', f'href="../department_{period}.html"')
```

**결과**:
- ✅ HTML 파일 더블클릭으로 바로 실행 가능
- ✅ 서버 불필요
- ✅ USB/로컬 공유 가능
