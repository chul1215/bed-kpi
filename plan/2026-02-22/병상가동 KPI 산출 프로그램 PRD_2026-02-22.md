## 1. 개요 (Overview)

### 1.1 배경

선메디컬센터(대전선병원/유성선병원)는 심평원(HIRA) 기준 재원일수 대비 자체 재원일수의 격차를 정량적으로 파악하고, 이를 기반으로 병상가동률 개선 전략을 수립할 필요가 있다. 현재 시기별(비수기/통상기간) 운영 데이터를 체계적으로 분석하는 도구가 없어, 진료과-의료진-질환 단위의 목표 관리가 어려운 상황이다.

### 1.2 목적

1. 심평원 기준치(재원일수) 대비 격차를 정량화하여 **"얼마나 조정해야 하는지(증감)"** KPI로 제시
2. **비수기(3-4월, 11-12월) / 통상기간(1-2월, 5-10월)** 으로 목표를 분리하여 운영 전략의 우선순위를 명확히 함
3. 산출 결과를 바탕으로 **진료과-의료진-질환 단위의 목표 관리 체계** 구축 및 병상가동 개선 효과 연결

### 1.3 대상 사용자

| 사용자 | 역할 | 주요 니즈 |
|--------|------|-----------|
| 적정진료관리팀 | 데이터 업로드, KPI 산출, 보고서 생성 | 빠른 산출 및 브리핑 자료 생성 |
| 병원 경영진 | KPI 결과 열람, 의사결정 | 요약 대시보드 및 핵심 인사이트 |
| 진료과장/의료진 | 본인 성과 확인 | 개인별 질환별 상세 KPI 조회 |

### 1.4 용어 정의

| 용어                   | 정의                           |
| -------------------- | ---------------------------- |
| LOS (Length of Stay) | 재원일수. 병상일수 / 환자수로 산출         |
| 병상일수                 | 재원일수 합계 (LOS 합산값)            |
| 환자수                  | 퇴원건수 기준                      |
| HIRA 목표 LOS          | 심평원 제공 2차종합병원 기준 재원일수        |
| LOS 갭                | HIRA_목표_LOS - 현재_LOS (양수: 늘려야 함, 음수: 줄여야 함) |
| 추가 병상일수              | LOS_갭 x 환자수                  |
| 비수기                  | 3-4월, 11-12월                 |
| 통상기간                 | 1-2월, 5-10월                  |

#### FR-03. KPI 산출 엔진

| 항목 | 상세 |
|------|------|
| **ID** | FR-03 |
| **우선순위** | P0 (필수) |
| **설명** | 핵심 KPI를 산출한다 |

**산출 로직:**

```
1. 현재 LOS = 병상일수 / 환자수
2. LOS 갭 = HIRA_목표_LOS - 현재_LOS (양수/음수 유지)
3. 추가 병상일수 = LOS 갭 x 환자수 (양수: 증가 필요, 음수: 감소 필요)
4. 기간 가동률(목표) = (현재_병상일수 + 추가_병상일수) / (병상수 x 기간일수)
5. 임팩트(우선순위 점수) = 추가 병상일수
```

**인수 조건:**
- [ ] 질환 단위 KPI 산출: 질환별로 LOS 갭, 추가 병상일수 직접 계산
- [ ] 의료진 단위 KPI 산출: 해당 의료진의 질환 믹스를 반영한 가중 평균 목표 LOS 적용
  - `의료진_목표_LOS = Σ(질환_목표_LOS × 질환 환자수 비중)`
- [ ] 기간별(비수기/통상기간) 분리 산출
- [ ] 최소 환자수 기준(기본값: 6명) 미만 데이터 제외 처리
- [ ] 환자수 0 또는 병상일수 0인 경우 해당 항목 제외 및 별도 표기
- [ ] 진료과 합계 = 전체 합계 정합성 검증 통과

## 4. 데이터 명세 (Data Specification)

### 4.1 내부 실적 데이터 (입력 파일 1)

| 컬럼명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| 병원명 | TEXT | Y | 대전선병원 / 유성선병원 구분 | 유성선병원 |
| 기준월 | TEXT | Y | YYYY-MM 형식 | 2025-03 |
| 진료과 | TEXT | Y | 진료과명 | 내과 |
| 의료진 | TEXT | Y | 의료진명 | 홍길동 |
| 질환 | TEXT | Y | 질환명 또는 진단군 | 폐렴 |
| 환자수 | INTEGER | Y | 퇴원건수 기준 | 120 |
| 병상일수 | INTEGER | Y | 재원일수 합계 | 960 |

**의료진명 처리 규칙:**
- 공백 포함 시 공백 전 첫 번째 이름을 의료진명으로 인식 (예: "홍길동 교수" → "홍길동")

**파생값 (시스템 산출):**
- `현재_LOS = 병상일수 / 환자수`

### 4.2 심평원 기준 데이터 (입력 파일 2)

| 컬럼명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| 질환 | TEXT | Y | 질환명 또는 진단군 (내부 데이터와 매칭 키) | 폐렴 |
| 기준_재원일수 | FLOAT | Y | HIRA 목표 LOS (2차종합병원 기준) | 10.5 |
| 기간구분 | TEXT | N | 월별/연도별 (제공 시) | 2025 |

**※ 심평원 데이터 특이사항:**
- 의사 항목, 환자수 항목 미포함
- **DRG 코드 매칭 규칙:**
  - 심평원 코드(4자리) → 앞 3자리로 병원 질병코드(3자리)와 매칭
  - 명칭도 함께 확인하여 매칭 정확도 향상

### 4.3 산출 데이터 (출력)

| 컬럼명 | 산출식 | 단위 |
|--------|--------|------|
| 현재_LOS | 병상일수 / 환자수 | 일 |
| LOS_갭 | HIRA_목표_LOS - 현재_LOS (양수/음수 유지) | 일 |
| 추가_병상일수 | LOS_갭 x 환자수 | 일 |
| 기간_가동률_현재 | 현재_병상일수 / (병상수 x 기간일수) | % |
| 기간_가동률_목표 | (현재_병상일수 + 추가_병상일수) / (병상수 x 기간일수) | % |
| 의료진_목표_LOS | Σ(질환_목표_LOS x 질환_환자수_비중) | 일 |
| 임팩트_점수 | 추가_병상일수 | 일 |

## 5. KPI 산출 규칙 상세

### 5.1 기본 규칙

```
IF 환자수 < 최소기준(6) THEN 산출 제외 (별도 표기)
IF 환자수 = 0 OR 병상일수 = 0 THEN 산출 제외 (별도 표기)
LOS_갭 = HIRA_목표_LOS - 현재_LOS (양수: 늘려야 함, 음수: 줄여야 함 → 양방향 표시)
```

### 5.2 기간 합산 규칙

- 비수기(3-4월, 11-12월) 데이터를 **기간 합산**하여 산출
  - 환자수: 해당 기간 월별 환자수 합계
  - 병상일수: 해당 기간 월별 병상일수 합계
  - LOS: 합산 병상일수 / 합산 환자수

### 5.3 의료진 목표 LOS 분배 로직

심평원 자료가 **질환(진단군) 기준**으로 제공되므로:

```
의료진 A의 목표 LOS 산출:
  1. 의료진 A가 담당한 질환 목록 조회
  2. 각 질환의 환자수 비중 계산: 비중_i = 질환_i_환자수 / 의료진_전체_환자수
  3. 가중 평균: 의료진_목표_LOS = Σ(질환_i_HIRA_LOS x 비중_i)
```

### 5.4 데이터 매칭 규칙

- 내부 데이터의 `질환`과 심평원 데이터의 `질환`을 키로 매칭
- **DRG 코드 매칭**: 심평원 코드(4자리)의 앞 3자리로 병원 질병코드(3자리)와 매칭 + 명칭 확인으로 정확도 향상
- 매칭 실패 시 해당 건 별도 "미매칭 목록"으로 분리하여 사용자에게 표시
- 사용자가 수동 매핑할 수 있는 UI 제공 (2차)

## 6. 화면 설계 (Information Architecture)

### 6.1 화면 구성

```
[공통 헤더]
├── 병원 탭: [대전선병원] / [유성선병원]
├── 기간 토글: 비수기 / 통상기간 / 월별
├── 메뉴: 홈 | 진료과 | 의료진 | 질환
└── 데이터 업로드 버튼

[1] 데이터 업로드
    ├── 내부 실적 파일 업로드 영역
    ├── 심평원 기준 파일 업로드 영역
    ├── 옵션 설정 (최소 환자수, 표기 방식)
    └── KPI 산출 시작 버튼

[2] 홈 (전체 요약)
    ├── KPI 카드 3종 (평균 LOS 갭 / 추가 병상일수 / 목표 가동률)
    ├── 의사별 질환 TOP 6 랭킹 + 의사 KPI
    ├── 핵심 인사이트 (자동 생성)
    └── 다운로드 버튼

[3] 진료과 뷰
    ├── 진료과 목록 + KPI 테이블
    └── 진료과 선택 → 소속 의료진 랭킹 펼침

[4] 의료진 뷰
    ├── 의료진 검색
    ├── 개인 KPI 요약 카드
    ├── 질환별 KPI 상세 테이블
    └── 목표 달성 시 예상 변화 요약

[5] 질환 뷰 (옵션)
    ├── 질환 검색
    ├── HIRA 기준 LOS vs 병원 현황 비교
    ├── 담당 의료진 분포 테이블
    └── 월별 LOS 추이 차트
```

### 6.2 화면 흐름

```
데이터 업로드 → 홈(요약)
                  ├── 진료과 뷰 → 의료진 랭킹
                  ├── 의료진 뷰 → 질환별 상세
                  └── 질환 뷰 → 의료진 분포
```

## 9. 검증 체크리스트

### 9.1 개발 전 확인 사항 (확인 완료)

| 항목 | 확인 결과 |
|------|-----------|
| 심평원 기준 재원일수 제공 레벨 | **질환 기준** |
| 내부 실적 환자수 기준 | **퇴원건수 기준** |
| 기간별 KPI 산출 방식 | **기간 합산** (월별 먼저 X) |
| 병상가동률 분모 | **기간 병상수 x 일수** |
| 최소 표본 기준 | **환자수 6명 이상** (기존과 동일) |
| KPI 톤 | **운영 참고치** (목표 강제 아님) |

### 9.2 1차 브리핑 후 검증 항목

- [ ] (정합성) 진료과 합계 = 전체 합계 일치 여부
- [ ] (분모) 환자수 0 / 병상일수 0 처리 규칙 적용 확인
- [ ] (저표본) 최소 환자수 기준 적용으로 KPI 왜곡 방지 확인
- [ ] (정책) 심평원 기준 연도/기관유형/평가군 매칭 정확성
- [ ] (해석) "운영 참고치" 톤 유지, 의료 질 저하 유도 오해 방지 문구 확인
