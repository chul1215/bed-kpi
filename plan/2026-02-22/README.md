## 🔑 핵심 개념

### DRG 매칭 방식 변경

**기존 (실패)**:
- HIRA DRG 코드(4자리) ↔ SMC 진단명
- 분류 체계 불일치 (수술/시술 vs 질환명)
- 매칭률 2.1% (14개/663개)

**변경 (성공)**:
- HIRA ADRG명 ↔ SMC 진단명 직접 비교
- 3단계 매칭: 수동 → 직접 → 부분
- 매칭률 14.2% (46개/324개)
- 의료진 데이터 표시 76%

### KPI 산출 규칙

```
1. 현재 LOS = 병상일수 / 환자수
2. LOS 갭 = HIRA_목표_LOS - 현재_LOS (양방향 유지)
3. 추가 병상일수 = LOS 갭 × 환자수
4. 의료진 목표 LOS = Σ(질환_목표_LOS × 질환_환자수_비중)
```
