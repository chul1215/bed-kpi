# 데이터 사전 식립 완료

## ✅ 변경 사항

### 1. 설정 추가 ([config.py](backend/app/config.py))

```python
# 프로젝트 루트 경로
PROJECT_ROOT = Path(__file__).parent.parent.parent

# 사전 식립 데이터 경로 (프로젝트 루트 기준)
PRELOADED_HIRA_FILE: Path = PROJECT_ROOT / "data/hira/2025_4분기_종합병원_ADRG별_평균재원)_20260220111626.xlsx"
PRELOADED_SMC_FILE: Path = PROJECT_ROOT / "data/smc/25년도 대전, 유성 의사별 퇴원진단(26.01.28_방하나).xlsx"
ENABLE_PRELOADED_DATA: bool = True  # 사전 식립 데이터 활성화
```

### 2. 데이터 사전 로더 생성 ([data_preloader.py](backend/app/services/data_preloader.py))

- 애플리케이션 시작 시 자동으로 HIRA/SMC 데이터 로드
- 대전/유성 병원별로 별도 세션 생성
- KPI 파이프라인 실행 및 결과 저장
- 기본 세션 ID 관리

### 3. 애플리케이션 시작 이벤트 추가 ([main.py](backend/app/main.py))

```python
@app.on_event("startup")
async def startup_event():
    """애플리케이션 시작 시 사전 식립 데이터 로드"""
    result = data_preloader.load_preloaded_data()
    # 대전/유성 병원 데이터 자동 로드
```

### 4. 모든 라우트에서 자동 세션 사용

- `session_id` 파라미터가 없으면 자동으로 사전 식립된 세션 사용
- 별도 업로드 없이 바로 실제 데이터 확인 가능

## 📈 장점

### 1. **즉시 사용 가능**
- 서버 시작하자마자 바로 대시보드 확인 가능

- 대전/유성 병원 데이터가 별도 세션으로 관리

### 4. **자동 갱신**
- 서버 재시작 시 최신 파일로 자동 로드
- 데이터 업데이트 후 재시작만 하면 됨
