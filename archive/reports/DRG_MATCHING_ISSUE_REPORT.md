### 3. 왜 매칭이 실패하는가?

#### 근본 원인: 분류 체계의 불일치

```
[HIRA 관점]
담석증 환자 → 담낭절제술 시행 → "담낭 수술" 또는 "담도 및 췌장 수술" DRG에 분류

[SMC 관점]
담석증 환자 → 진단명: "담석증"으로 기록

→ 매칭 불가!
```

**예시 비교**:

| SMC 진단명 | 예상되는 HIRA DRG | 실제 매칭 |
|------------|-------------------|-----------|
| 담석증 | "담낭 수술", "담도 및 췌장 수술" 등 | ❌ 없음 |
| 무릎관절증 | "슬관절 치환술", "기타 무릎 수술" 등 | ❌ 없음 |
| 급성 충수염 | "충수절제술" | ❌ 없음 |
| 대퇴골 골절 | "대퇴골 골절 수술", "고관절 수술" 등 | ❌ 없음 |

#### 구조적 차이

1. **HIRA**: 치료 행위 중심 (What was done?)
   - "간 이식술을 받은 환자"
   - "대동맥판막 수술을 받은 환자"

2. **SMC**: 질병 진단 중심 (What disease?)
   - "담석증 환자"
   - "무릎관절증 환자"

3. **1:N 관계**: 하나의 질환이 여러 DRG로 분류될 수 있음
   - 담석증 → 담낭절제술(수술) OR 내시경적 시술 OR 보존적 치료
   - 각각 다른 DRG 코드

### 2. 비즈니스 영향

- **KPI 산출 불가**: 심평원 기준 대비 개선 목표 설정 불가능
- **의사 결정 불가**: 어떤 진료과/의료진/질환에 집중해야 할지 판단 불가
- **목표 관리 불가**: "얼마나 재원일수를 조정해야 하는가" 정량적 목표 제시 불가
- **병상 가동 계획 불가**: 추가 병상일수 계산 불가로 가동률 목표 수립 불가

## 🔍 원인 분석

### 1. 기술적 원인

#### 현재 매칭 로직
```python
# drg_matcher.py의 매칭 방식
def get_target_los(diagnosis: str, hira_df: pd.DataFrame):
    # 1. 매핑 테이블 조회
    mapping_row = mapping_df[mapping_df['diagnosis'] == diagnosis]

    # 2. 매핑 테이블이 비어있음 → None 반환
    if mapping_row.empty:
        return None

    # 3. DRG 코드로 HIRA 조회
    drg_code = mapping_row['drg_code_3digit']
    hira_row = hira_df[hira_df['drg_code_3digit'] == drg_code]

    return hira_row['target_los']
```

**문제점**:
- 매핑 테이블(`data/mapping/diagnosis_drg_mapping.xlsx`)이 존재하지 않음
- 자동 매칭 시도도 실패 (진단명 vs ADRG명 문자열 비교 불가)

### 2. 데이터 구조적 원인

#### SMC 데이터에 DRG 코드 부재
```
현재 SMC 컬럼: 구분, 퇴원일자, 성별, 입원일자, 평균재원, 퇴원과, 진단명, 의사명
필요 컬럼:     DRG코드 (또는 수술/시술 코드)
```

#### HIRA 데이터에 진단명 부재
```
현재 HIRA 컬럼: 4단DRG번호, ADRG명, 평균재원일수
진단명 정보:    없음 (ADRG명이 수술명이므로)
```

### 3. 의료 정보 체계 차이

- **DRG**: 포괄수가제를 위한 환자 분류 체계 (치료 행위 기반)
- **ICD-10**: 질병 분류 체계 (진단명 기반)
- **둘은 서로 다른 목적과 체계**를 가짐

hospital_avg_los = hospital_total_bed_days / hospital_total_patients
los_gap = current_los - hospital_avg_los  # 병원 평균 대비

# 또는 진료과 평균 대비

#### 장점
