## 💡 기술적 해결 사항

### 문제 1: KDRG 4.6에 없는 ICD-10 코드

**원인**:
- KDRG 4.6 진단코드_ADRG매핑에 일부 ICD-10 코드가 없음
- 특히 증상 코드(R42, R51) 및 일부 악성 신생물 코드

**해결**:
- HIRA 파일에서 유사한 ADRG명 찾기
- 진단명 기반 수동 매핑 추가

**예시**:
```python
# 갑상선 악성 신생물 (C73) → KDRG에 없음
# HIRA에서 "갑상선" 검색 → "주요 갑상선수술, 단측" 발견
# 수동 매핑 추가
{
    'diagnosis': '갑상선의 악성 신생물',
    'adrg_name': '주요 갑상선수술, 단측'
}
```

### 문제 2: 구강/턱 관련 진단명 미매칭

**원인**:
- 유길화 의사의 주요 진단명 (구강영역의 낭, 턱의 질환)
- KDRG에 직접 매핑 안 됨

**해결**:
- HIRA에서 "안면골" 검색 → "안면골 골절 수술" 발견
- 수동 매핑 추가

**효과**:
- 유길화 의사 매칭률 **55.0% → 92.5%** (37.5%p 향상)
