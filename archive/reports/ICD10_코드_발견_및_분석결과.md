## 💡 해결 방안

### 방안 1: ICD-10 → ADRG 매핑 테이블 작성 (권장) ⭐

**생성된 파일**: `data/mapping/icd10_adrg_mapping_template.xlsx`

**템플릿 구조**:
| ICD-10 코드 | 진단명 | 환자수 | ADRG명 (수동 입력) | 비고 |
|-------------|--------|--------|-------------------|------|
| Z51 | 기타 의학적 관리... | 3,137 | (입력 필요) | |
| K80 | 담석증 | 1,146 | (입력 필요) | |
| M17 | 무릎관절증 | 1,143 | (입력 필요) | |
| ... | ... | ... | ... | ... |

**작업 방법**:
1. 템플릿 파일 열기: `data/mapping/icd10_adrg_mapping_template.xlsx`
2. "ICD10_매핑템플릿" 시트에서 `adrg_name` 컬럼 작성
3. "ADRG목록" 시트에서 적절한 ADRG명 검색하여 복사
4. 완성된 파일을 `icd10_adrg_mapping.xlsx`로 저장
5. 대시보드 재생성

**예상 효과**:
- 상위 100개 ICD-10 코드 매핑 시 **환자 커버리지 90.7%**
- 남선우 의료진 같은 케이스 대폭 개선 (12명 → 45명 전체 표시)

---

### 방안 2: KDRG 4.4 분류집에서 ICD-10 → DRG 매핑 테이블 확보

**문제**: 현재 HIRA 파일에는 DRG 코드만 있고 ICD-10 코드가 없음

**해결책**:
1. KDRG 4.4 분류집 원본 문서 확보
   - 심평원 또는 KDRG 공식 문서
   - ICD-10 → DRG 매핑 테이블 포함되어 있어야 함
2. 매핑 테이블을 엑셀로 변환
3. 자동 매칭 로직 구현

**예상 효과**:
- 완전 자동 매칭 (수동 작업 불필요)
- 환자 커버리지 **95%+**
- 유지보수 용이

## 📋 즉시 실행 가능한 작업

### 1단계: ICD-10 매핑 템플릿 작성 (수동)

**파일**: `data/mapping/icd10_adrg_mapping_template.xlsx`

**상위 20개 ICD-10 코드만 매핑해도**:
- 환자 커버리지: 약 50%
- 소요 시간: 약 30분

**예시 매핑** (참고용):

| ICD-10 | 진단명 | 제안 ADRG명 |
|--------|--------|------------|
| Z51 | 기타 의학적 관리... | 기타 의학적 관리를 위하여 보건서비스와 접하고 있는 사람 |
| K80 | 담석증 | 복강경을 이용한 전담낭절제술 |
| M17 | 무릎관절증 | 슬관절치환술 |
| I63 | 뇌경색증 | 뇌경색증 |
| K35 | 급성 충수염 | 복잡한 주진단이 없는 충수절제술 |

### 2단계: 파서 수정 (Sheet1 → 병원별 시트)

**현재**: `Sheet1` 시트 사용 (개별 환자 레코드, ICD-10 코드 없음)
**변경**: `병원별` 시트 사용 (의사별 질환 집계, ICD-10 코드 100%)

**수정 파일**: `backend/app/services/file_parser.py`

### 3단계: ICD-10 기반 매칭 로직 구현

**파일**: `backend/app/services/kdrg_matcher.py`

새로운 매칭 전략:
1. ICD-10 매핑 테이블 우선
2. 진단명 수동 매핑 테이블
3. 진단명 직접 일치
4. 진단명 부분 일치

### 4단계: 대시보드 재생성

```bash
python3 generate_static_dashboard.py
```
