**가장 큰 문제**:
- **뇌경색증 19명**이 KDRG 매칭 테이블에 없음!
- 전체 환자의 42.2% (19/45)가 단일 질환인데 미매칭

### 2. `calculate_doctor_disease_kpis()` 함수 로직

현재 함수는 **target_los가 있는 질환만** 반환합니다:

```python
def calculate_doctor_disease_kpis(doctor_name, smc_matched, disease_target_map, hospital, period):
    # 해당 의료진 데이터 필터링
    doctor_data = smc_matched[
        (smc_matched['doctor'] == doctor_name) &
        (smc_matched['hospital'] == hospital) &
        (smc_matched['period'] == period)
    ]

    # 질환별 집계
    disease_agg = doctor_data.groupby('diagnosis').agg({
        'los_days': ['sum', 'count', 'mean']
    }).reset_index()

    # 목표 LOS 추가
    disease_agg['target_los'] = disease_agg['diagnosis'].map(disease_target_map)

    # ⚠️ 여기서 문제 발생!
    # KPI 계산 시 target_los가 None이면 제외됨
    for _, row in disease_agg.iterrows():
        kpi = KPICalculator.calculate_disease_kpi({...})
        disease_kpis.append(kpi)

    # target_los가 없는 질환은 KPI가 None으로 반환되어 DataFrame에서 제외
```

### 3. `KPICalculator.calculate_disease_kpi()` 로직

```python
def calculate_disease_kpi(disease_data: Dict) -> Dict:
    if target_los is None:
        return {
            'diagnosis': diagnosis,
            'patient_count': patient_count,
            'current_los': current_los,
            'target_los': None,
            'los_gap': None,  # ⚠️ None
            'additional_bed_days': None  # ⚠️ None
        }
```

**문제**: `los_gap`과 `additional_bed_days`가 None인 질환은 정렬 시 제외되거나 화면에 표시되지 않음

### 방안 2: 미매칭 질환도 토글에 표시 (임시 해결)

**수정 위치**: `calculate_doctor_disease_kpis()` 함수

**현재 로직**:
```python
# target_los가 없으면 KPI가 None으로 반환

```

**개선 로직**:
```python
def calculate_doctor_disease_kpis(...):
    # 질환별 집계
    disease_agg = doctor_data.groupby('diagnosis').agg({
        'los_days': ['sum', 'count', 'mean']
    }).reset_index()

    # 목표 LOS 추가
    disease_agg['target_los'] = disease_agg['diagnosis'].map(disease_target_map)

    # 모든 질환에 대해 KPI 계산 (target_los가 없어도 포함)
    disease_kpis = []
    for _, row in disease_agg.iterrows():
        kpi = {
            'diagnosis': row['diagnosis'],
            'patient_count': int(row['patient_count']),
            'current_los': float(row['current_los']),
            'total_bed_days': float(row['total_bed_days']),
            'target_los': row['target_los'] if pd.notna(row['target_los']) else None,
            'los_gap': (row['target_los'] - row['current_los']) if pd.notna(row['target_los']) else None,
            'additional_bed_days': ((row['target_los'] - row['current_los']) * row['patient_count'])
                                   if pd.notna(row['target_los']) else None
        }
        disease_kpis.append(kpi)

    # 정렬: additional_bed_days 우선, None은 뒤로
    disease_kpis_df = pd.DataFrame(disease_kpis)

    # additional_bed_days를 기준으로 정렬 (None은 환자수 기준으로 정렬)
    disease_kpis_df['sort_key'] = disease_kpis_df.apply(
        lambda x: x['additional_bed_days'] if pd.notna(x['additional_bed_days'])
                  else -x['patient_count'],  # None인 경우 환자수로 역정렬
        axis=1
    )
    disease_kpis_df = disease_kpis_df.sort_values('sort_key', ascending=False)
    disease_kpis_df = disease_kpis_df.drop('sort_key', axis=1)

    return disease_kpis_df
```

**장점**:
- ✅ 즉시 적용 가능
- ✅ 모든 질환 표시 (45명 전체 커버)
- ✅ 환자수 정합성 확보

**단점**:
- ❌ 미매칭 질환은 LOS 갭, 추가재원일수가 "N/A"로 표시
- ❌ KPI 평가 불가능
