## 💡 개선 방안

### 1. 즉시 개선 가능 (수동 매핑 추가)

다음 진단명들을 `diagnosis_kdrg44_mapping.xlsx`에 추가하면 개선 가능:

| 진단명 | 제안 ADRG명 | 예상 효과 |
|--------|------------|----------|
| 급성 편도염 | 편도 및 아데노이드수술 | 장희상, 신명석 +6명 |
| 침샘의 질환 | 침샘 수술 또는 기타 안면골 절제술 | 신명석 +4명 |
| 언어장애 | 신경계통의 기타 장애 | 김병석 +4명 |
| 피부감각의 장애 | 신경계통의 기타 장애 | 김병석 +3명 |

**예상 개선**:
- 신명석: 77.9% → ~85%
- 장희상: 75.4% → ~80%
- 김병석: 77.0% → ~85%

### 2. KDRG/HIRA에 없는 진단명

다음은 KDRG/HIRA 모두에 없어 개선 어려움:

- **죽상경화증 (I70)**: 윤병준 4명, 조성래 3명
- **천식 (J45)**: 이연선 3명

**해결 방법**:
1. 병원 측에 DRG 청구 데이터 확인 요청
2. 유사 질환으로 수동 매핑 (예: 죽상경화증 → 말초혈관질환)

### 3. ICD-10 코드 누락 진단명

병원별 시트에 ICD-10 코드가 없는 진단명들은 병원 측에 데이터 보완 요청 필요.

## 📋 결론

### 주요 발견사항

1. **전체 160명 중 9명만 80% 미만** (5.6%)
2. **유성선병원이 대전선병원보다 매칭률 높음** (평균 93.7% vs 90.2%)
3. **주요 미매칭 원인**:
   - KDRG에 없는 ICD-10 코드 (I70, J45, J03 등)
   - 병원 데이터에 ICD-10 코드 누락
   - 증상 코드(R로 시작) KDRG 미포함

### 권장사항

1. **즉시 개선 가능 (30분 작업)**:
   - 급성 편도염, 침샘의 질환, 언어장애, 피부감각장애 수동 매핑 추가
   - 예상 효과: 4명의 의료진 80% 이상 달성

2. **병원 측 요청 사항**:
   - ICD-10 코드 누락 진단명 보완
   - DRG 청구 데이터 확인 (ADRG 코드 포함 여부)

3. **장기 개선**:
   - 심평원 공식 ICD-10 → KDRG 매핑 테이블 확보
   - 진료과별 의료진 협의를 통한 수동 매핑 확장
