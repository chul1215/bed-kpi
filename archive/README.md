# Archive

이 폴더는 개발 과정의 히스토리를 보관하는 아카이브입니다.

## 구조

- `reports/`: 개발 단계별 보고서 및 분석 결과
- `scripts/`: 일회성 또는 임시 스크립트
- `old_docs/`: 구버전 문서

## 현재 사용 중인 주요 문서

프로젝트 루트의 다음 문서를 참조하세요:
- `CLAUDE.md`: 개발 가이드 (최신)
- `README.md`: 프로젝트 개요
- `실행방법.md`: 사용자 가이드
- `TOP10_매핑_개선_완료_보고서.md`: 1단계 개선 결과
- `2단계_ICD10_전체_매핑_완료_보고서.md`: 2단계 개선 결과 (최종)
