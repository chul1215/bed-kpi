# 선메디컬센터 병상가동률 개선 KPI 산출 시뮬레이터

대전선병원·유성선병원 의사별 진단 기준 **목표 재원일수**를 산출하고, 비수기·통상기간별 병상가동률 개선 조정 대상을 시각화하는 단일 HTML 대시보드입니다.

---

## 주요 기능

- **병원 탭 전환** — 대전선병원 / 유성선병원 각각 독립 조회
- **의사별 TOP7 진단** — 환자수 6명 이상 진단 중 상위 7개 표시
- **비수기·통상기간 목표 산출** — 비수기(3·4·11·12월) 85% / 통상(1·2·5~10월) 90% 가동률 기준
- **연간 목표(88.3%)** — 연간 전체 기준 목표 재원일수 별도 컬럼 제공
- **심평원 비교** — 전국 평균(HIRA) 대비 현재 재원일수 차이 표시
- **필터·검색** — 전체 / 조정필요 / 심평원有 모드 + 진단명·의사명 검색
- **컬럼 정렬** — 전체 컬럼 오름차순·내림차순 정렬
- **진료과 그룹 드롭다운** — 의사 선택 시 진료과별 그룹화

## 비즈니스 로직 요약

| 항목 | 대전선병원 | 유성선병원 |
|------|-----------|-----------|
| 허가병상 | 332병상 | 387병상 |
| 현재 가동률 | 82.0% | 72.1% |
| 목표 가동률 | 88.3% | 88.3% |
| 조정 방향 | 연장 (늘려야) | 연장 (늘려야) |
| 레코드 수 | 255건 / 43명 | 286건 / 50명 |

**목표 재원일수 산출 공식**

```
off_ratio  = (beds × 122일 × 85%) / 비수기 현재 총재원일수
norm_ratio = (beds × 243일 × 90%) / 통상 현재 총재원일수

tgt_off  = cur_off  × off_ratio
tgt_norm = cur_norm × norm_ratio
diff     = cur - tgt  (음수 → 늘려야 함, 양수 → 줄여야 함)
```
